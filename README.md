# Radar-Image-Intention-Recognition-in-Earth_Shadow
ST-DLAN for Intention Recognition of Space Non-Cooperative Targets from Radar Image Sequences in Earth's Shadow
The primary function of this repository is to provide the code and dataset related to the paper "ST-DLAN for Intention Recognition of Space Non-Cooperative Targets from Radar Image Sequences in Earth's Shadow." The abstract of the paper is as follows:

"In space situational awareness, accurate intention recognition of space non-cooperative targets provides valuable information for satellite-system decision-making and contributes to orbital safety. However, in Earth's-shadow regions where target-intention recognition relies on microwave radar, existing intention-recognition methods have yet to establish a direct mapping from low-level radar observations. To address this issue, we establish the first end-to-end framework that directly uses radar images acquired by an X-band \(8\times8\) spaceborne phased-array radar to recognize the intentions of space non-cooperative targets. First, to the best of our knowledge, we construct the first simulated dual-channel radar image-sequence dataset for intention recognition, integrating plan position indicator (PPI) and Doppler short-time Fourier transform (STFT) images based on the scanning mechanism of phased-array radar. Unlike conventional radar target tracking, which requires high power consumption and high measurement precision, the proposed imaging method generates radar images under relaxed sensing requirements. Then, using ConvLSTM as the backbone, we introduce a symmetric downsampling layer and a multi-head self-attention mechanism to develop a simple and efficient end-to-end Spatiotemporal Decoupled Late-Attention Network (ST-DLAN). Experimental results demonstrate that the proposed network achieves stable performance under both high- and low-SNR conditions."

The proposed model builds extensively on the ConvLSTM architecture ([1]Shi, Xingjian, et al. "Convolutional LSTM network: A machine learning approach for precipitation nowcasting." Advances in neural information processing systems 28 (2015).), using ConvLSTM as its backbone and incorporating a CNN-based symmetric downsampling module and a residual multi-head self-attention mechanism.
The currently provided code and dataset do not fully cover the experiments in the paper. Our team will continue to supplement and update them in the future.
